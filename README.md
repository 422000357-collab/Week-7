Scenario:
This program demonstrates basic Dart programming concepts, including variables, arithmetic operations, comparison operators, and output using `print()`.

The program stores information about a person, calculates their age next year, checks whether they are an adult, and checks whether a favorite number is greater than 10.

How to Run the Program:

1. Make sure Dart is installed on your computer.
2. Save the program as `main.dart`.
3. Open a terminal in the project folder.
4. Run the program using:

```bash
dart run main.dart
